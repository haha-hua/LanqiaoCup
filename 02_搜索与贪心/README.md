# 02_搜索与贪心

本目录包含搜索算法（DFS/BFS/对半搜索）和贪心算法的模板与经典例题。

## 文件列表与解析

- [1_全排列DFS模板.cpp](02_搜索与贪心/1_全排列DFS模板.cpp)
  - 描述：基于递归回溯的全排列生成模板。使用 visited 数组标记已选择的元素。
  - 时间复杂度：O(n!)，输出所有排列。
  - 参考题目：P1706（全排列问题）  https://www.luogu.com.cn/problem/P1706

- [2_网格图DFS模板.cpp](02_搜索与贪心/2_网格图DFS模板.cpp)
  - 描述：在二维网格上进行深度优先搜索，遍历相邻的可达点。
  - 时间复杂度：O(nm)，遍历每个格子最多一次。
  - 参考题目：P1162（填涂颜色）  https://www.luogu.com.cn/problem/P1162

- [3_带剪枝的深搜.cpp](02_搜索与贪心/3_带剪枝的深搜.cpp)
  - 描述：搜索时使用各类剪枝策略（可行性剪枝、限界剪枝等）减少搜索树规模。
  - 时间复杂度：取决于剪枝效率，最坏 O(指数)。
  - 参考题目：P9241（蓝桥杯 2023 省 B 飞机降落）  https://www.luogu.com.cn/problem/P9241

- [4_对半搜索模板.cpp](02_搜索与贪心/4_对半搜索模板.cpp)
  - 描述：将问题分为两部分，分别搜索后合并结果，用于解决某些指数级问题。
  - 时间复杂度：O(2^(n/2) * log(2^(n/2))) 或 O(2^(n/2) * n)，通常比完全搜索快得多。
  - 参考题目：P4799（CEOI 2015 世界冰球锦标赛）  https://www.luogu.com.cn/problem/P4799

- [5_区间贪心.cpp](02_搜索与贪心/5_区间贪心.cpp)
  - 描述：对区间进行排序（通常按左端点或右端点），然后贪心地选择或覆盖。
  - 时间复杂度：O(n log n)（排序）+ O(n)（贪心过程）。
  - 参考题目：P1803（线段覆盖）  https://www.luogu.com.cn/problem/P1803

- [6_反悔贪心.cpp](02_搜索与贪心/6_反悔贪心.cpp)
  - 描述：贪心做选择后，如果发现不是最优可以撤销（通常配合堆或其他数据结构）。
  - 时间复杂度：取决于悔棋操作，常见 O(n log n)。
  - 参考题目：P2949（工作调度）  https://www.luogu.com.cn/problem/P2949
