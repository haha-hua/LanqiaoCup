## 算法详解

### 字符串哈希
- **应用场景**：快速判断字符串相等、子串匹配、字符串去重
- **核心思想**：将字符串映射为数值，通过比较数值判断字符串是否相等
- **实现方式**：
  - 单哈希：选择一个基数 P（如 131, 13331）和模数 M
  - 双哈希：使用两组不同的 P 和 M，降低冲突概率
  - 自然溢出：使用 `unsigned long long`，相当于对 2^64 取模
- **子串哈希计算**：`hash[l,r] = hash[r] - hash[l-1] * P^(r-l+1)`
- **时间复杂度**：预处理 O(n)，查询 O(1)

### KMP 算法
- **应用场景**：字符串模式匹配、查找子串位置
- **核心思想**：利用已匹配部分的信息，避免回溯主串指针
- **关键概念**：
  - `next` 数组（部分匹配表）：记录模式串前缀与后缀的最长公共长度
  - 失配时跳转到 `next[j-1]` 位置继续匹配
- **时间复杂度**：预处理 O(m)，匹配 O(n)，总体 O(n+m)
- **扩展应用**：循环节判断、字符串周期问题

## 使用建议

- **字符串哈希**：
  - 适用于需要频繁比较字符串的场景
  - 双哈希可大幅降低冲突概率，推荐在重要比赛中使用
  - 注意选择合适的基数和模数组合
  
- **KMP 算法**：
  - 单次匹配问题首选，效率稳定
  - 理解 `next` 数组的构造原理是关键
  - 可扩展到多模式匹配（AC 自动机）
