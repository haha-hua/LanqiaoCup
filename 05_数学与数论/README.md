## 算法详解

### 快速幂
- **应用场景**：计算 a^b mod m，处理大数幂运算
- **核心思想**：二进制拆分，`a^b mod m` 可分解为 `a^(b1*2^0) * a^(b2*2^1) * ...`
- **时间复杂度**：O(log b)

### 素数筛选
- **应用场景**：快速筛出范围内所有素数
- **方法**：埃拉托斯特尼筛法，依次标记每个素数的倍数
- **时间复杂度**：O(n log log n)

### 最大公约数与最小公倍数
- **应用场景**：分数化简、数论计算
- **欧几里得算法**：gcd(a, b) = gcd(b, a mod b)
- **关系式**：lcm(a, b) = a * b / gcd(a, b)

### 扩展欧几里得算法
- **应用场景**：求解线性丢番图方程 ax + by = gcd(a,b)
- **用途**：模逆元计算、同余方程求解
- **实现**：回溯追踪 gcd 过程中的系数

### 组合数学
- **应用场景**：动态规划中的计数问题
- **实现方式**：杨辉三角预处理 / 阶乘逆元预处理
- **性质**：C(n,m) = C(n-1,m-1) + C(n-1,m)

## 使用建议

- **快速幂**：竞赛中极为常见，建议熟记模板
- **素数筛**：可根据范围选择不同优化方法（线性筛等）
- **gcd/lcm**：基础工具，经常与其他算法组合
- **扩展欧**：难度较高，理解原理很重要
- **组合数学**：需注意模数处理，避免溢出
