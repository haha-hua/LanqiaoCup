# 08_图论

本目录汇总图论相关算法模板，涵盖最短路径、最小生成树、树上问题、连通性等核心内容。每个文件附简要说明、适用场景、算法特点与参考题目。

## 文件列表与解析

- [1_Dijkstra最短路径.cpp](08_图论/1_Dijkstra最短路径.cpp)
  - 描述：Dijkstra单源最短路径算法模板，使用优先队列优化
  - 适用场景：求解带权有向图或无向图中从单个源点到其他所有点的最短路径
  - 算法特点：时间复杂度 O((V+E)logV)，不能处理负权边
  - 参考题目：P4779 【模板】单源最短路径（标准版） — https://www.luogu.com.cn/problem/P4779

- [2_SPFA判断负环.cpp](08_图论/2_SPFA判断负环.cpp)
  - 描述：SPFA算法判断负环模板，基于Bellman-Ford的队列优化
  - 适用场景：检测图中是否存在负权环，可用于求解最短路径（但效率不稳定）
  - 算法特点：平均时间复杂度 O(kE)，最坏 O(VE)，通过记录路径边数判断负环
  - 参考题目：P3385 【模板】负环 — https://www.luogu.com.cn/problem/P3385

- [3_Kruskal最小生成树.cpp](08_图论/3_Kruskal最小生成树.cpp)
  - 描述：Kruskal最小生成树算法模板，基于贪心思想和并查集
  - 适用场景：求解无向连通图的最小生成树，特别适合稀疏图
  - 算法特点：时间复杂度 O(E log E)，将边按权重排序后依次选择不形成环的边
  - 参考题目：P3366 【模板】最小生成树 — https://www.luogu.com.cn/problem/P3366

- [4_prim最小生成树.cpp](08_图论/4_prim最小生成树.cpp)
  - 描述：Prim最小生成树算法模板，基于贪心思想和优先队列
  - 适用场景：求解无向连通图的最小生成树，特别适合稠密图
  - 算法特点：时间复杂度 O(E log V)，从任意顶点开始逐步扩展生成树
  - 参考题目：P3366 【模板】最小生成树 — https://www.luogu.com.cn/problem/P3366

- [5_LCA公共祖先.cpp](08_图论/5_LCA公共祖先.cpp)
  - 描述：LCA（最近公共祖先）算法模板，使用倍增法实现
  - 适用场景：在树结构中快速查询任意两点的最近公共祖先
  - 算法特点：预处理 O(N log N)，单次查询 O(log N)，通过预处理2^i级祖先实现快速跳转
  - 参考题目：P3379 【模板】最近公共祖先（LCA） — https://www.luogu.com.cn/problem/P3379

- [6_树的直径.cpp](08_图论/6_树的直径.cpp)
  - 描述：树的直径算法模板，使用两次DFS/BFS求解最长路径
  - 适用场景：求解无根树中最长路径的长度（边数）
  - 算法特点：时间复杂度 O(N)，基于树的性质：从任意点出发的最远点必为直径端点之一
  - 参考题目：B4016 树的直径 — https://www.luogu.com.cn/problem/B4016

- [7_树上点差分.cpp](08_图论/7_树上点差分.cpp)
  - 描述：树上点差分算法模板，处理树上路径的批量修改和查询
  - 适用场景：多次对树上路径进行区间修改，最后统计各点的值
  - 算法特点：单次修改 O(1)，最终统计 O(N)，结合LCA实现差分标记
  - 参考题目：P3128 [USACO15DEC] Max Flow P — https://www.luogu.com.cn/problem/P3128

- [8_树上边差分.cpp](08_图论/8_树上边差分.cpp)
  - 描述：树上边差分算法模板，将边权转化为点权处理
  - 适用场景：多次对树上路径的边进行区间修改，最后统计各边的值
  - 算法特点：通过子节点代表父边的方式，差分标记为 d[u]++, d[v]++, d[lca] -= 2
  - 参考题目：P10931 闇の連鎖 — https://www.luogu.com.cn/problem/P10931

- [9_Tarjan缩点.cpp](08_图论/9_Tarjan缩点.cpp)
  - 描述：Tarjan缩点算法模板，将强连通分量缩成单个点得到DAG
  - 适用场景：处理有向图的强连通分量问题，在缩点后的DAG上进行拓扑排序或DP
  - 算法特点：线性时间复杂度 O(V + E)，基于DFS的low值和dfn值判断强连通分量
  - 参考题目：P3387 【模板】缩点 — https://www.luogu.com.cn/problem/P3387

## 使用建议

1. **最短路径问题**：优先使用Dijkstra（无负权边）或SPFA（可能有负权边）
2. **最小生成树**：稀疏图用Kruskal，并查集实现简单；稠密图用Prim，邻接表实现
3. **树上问题**：LCA是基础工具，点差分和边差分是处理树上路径问题的重要技巧
4. **连通性问题**：Tarjan算法可解决强连通分量、割点、桥等多种连通性问题
