# 01_基础杂项

本目录汇总竞赛模板与常用工具函数，便于速写与在比赛中直接复用。每个文件附简要说明、适用场景与参考题目。
## 文件列表与解析

- [1_快读快写.cpp](01_基础杂项/1_快读快写.cpp)
	- 描述：提供基于 `getchar`/`putchar` 的快速读写函数（整型）。适用于大输入输出场景。
- [2_离散化.cpp](01_基础杂项/2_离散化.cpp)
	- 描述：离散化坐标压缩技术模板，适用于坐标、权值范围过大但不同取值较少的场景。
	- 复杂度：排序 O(n log n)，查询与映射 O(log n)（或 O(1) 使用哈希/映射表）。
- [3_二分查找.cpp](01_基础杂项/3_二分查找.cpp)
	- 描述：二分查找与判定函数模板，包含整数/浮点与答案空间二分常用模板。
	- 复杂度：每次判定 O(f(n))，总复杂度 O(f(n) * log(range))。对于安置问题通常为 O(n log V)。
- [4_一维前缀和一维差分.cpp](01_基础杂项/4_一维前缀和一维差分.cpp)
	- 描述：包含一维前缀和用于快速区间求和，以及一维差分用于快速区间加/范围修改的模板。
	- 复杂度：前缀和预处理 O(n)，每次区间和查询 O(1)；差分区间修改 O(1)，最终恢复数组 O(n)。
- [5_二维前缀和二维差分.cpp](01_基础杂项/5_二维前缀和二维差分.cpp)
	- 描述：二维前缀和用于矩阵区域和查询；二维差分用于矩阵的批量区域修改。
	- 复杂度：预处理 O(nm)，单次查询 O(1)；二维差分区域修改 O(1)，恢复矩阵 O(nm)。
- [6_int128大整数输入输出.cpp](01_基础杂项/6_int128大整数输入输出.cpp)
	- 描述：`__int128` 的输入输出与应用示例，适合处理超 64 位但结果仍能放进 128 位的乘法/累加场景。
	- 复杂度：与基本整数运算一致；注意打印与读入需要自定义函数。
- [7_高精度加减乘除.cpp](01_基础杂项/7_高精度加减乘除.cpp)
	- 描述：大整数字符串表示的加/减/乘/除（常见四则运算）模板。
	- 复杂度：加减 O(n)，乘法 O(n^2)（可替换 FFT/karatsuba 优化），除法 O(n^2) 或更优算法。

3_二分查找:
题目链接:https://ybt.ssoier.cn/problem_show.php?pid=1433(1433：【例题1】愤怒的牛)
这道题就是经典的二分查找题目，题目的意思就是二分(使任意两头牛之间的最小距离尽可能的大)，那么我们就是去直接二分距离，如果一个距离dist能放得下，那我们就增大，如果不行就减小，每次操作都是O(logn)的时间复杂度，总体就是O(nlogn);

一维前缀和
题目链接:https://www.luogu.com.cn/problem/P8218(P8218 【深进1.例1】求区间和)
这道题如果说从区间[l,r]慢慢累加那么就是O(n)，如果有m次访问那就是O(nm)，不可接受;

这道题就是需要大量修改，如果遍历区间[l,r]那么时间复杂度就是O(n),利用差分可以使得修改值变为O(1);
