## 学习建议

1. **背包入门**：从基础背包开始，理解"最优子结构"和"状态转移"
2. **树形 DP**：学习在树结构上递推，如树形、树上分组背包
3. **区间 DP**：解决区间类问题，如矩阵链乘、石子合并
4. **状态压缩**：用位掩码表示状态，适用于 n ≤ 20 的问题
5. **数位 DP**：处理数字特性的问题，常见于范围计数类

## 贡献与规范

- 新增文件：请使用数字前缀保持排序（例如 `9_xxx.cpp`）
- 文件头：已包含用途、时间复杂度、DP 定义与状态转移说明
- 提交规范：PR 请描述修改点、示例题目与复杂度分析
- **二维 DP**：dp[i][j] = 两个维度的最优值
- **计数 DP**：dp[j] = 满足条件的方案数

### 转移顺序
- **01背包**：逆序遍历容量（保证每件物品只用一次）
- **完全背包**：正序遍历容量（保证每件物品可用多次）
- **分组背包**：按组分别转移，容量正序

### 常见优化
- **二进制分组**：多重背包中用 O(log s) 个虚拟物品替代 s 个物品
- **DP + 贪心**：在某些问题中结合贪心思想
- **滚动数组**：节省二维数组空间
