## 核心概念

### 状态定义
- **一维 DP**：dp[j] = 容量为 j 时的最优值
- **二维 DP**：dp[i][j] = 两个维度的最优值
- **计数 DP**：dp[j] = 满足条件的方案数

### 转移顺序
- **01背包**：逆序遍历容量（保证每件物品只用一次）
- **完全背包**：正序遍历容量（保证每件物品可用多次）
- **分组背包**：按组分别转移，容量正序

### 常见优化
- **二进制分组**：多重背包中用 O(log s) 个虚拟物品替代 s 个物品
- **DP + 贪心**：在某些问题中结合贪心思想
- **滚动数组**：节省二维数组空间
