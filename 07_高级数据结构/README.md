## 算法详解

### 并查集
- **应用场景**：动态连通性问题、集合合并与查询
- **核心思想**：用树结构表示集合，通过路径压缩和按秩合并优化
- **关键操作**：
  - `findfa(x)`：查找 x 所在集合的根节点（路径压缩）
  - `merge(x, y)`：合并 x 和 y 所在的集合（按秩合并）
- **时间复杂度**：O(α(n))，α 为阿克曼函数的反函数
- **扩展应用**：带权并查集、时光倒流并查集、并查集+DP

### 树状数组
- **应用场景**：单点修改/区间查询、区间修改/单点查询、区间修改/区间查询
- **核心思想**：利用二进制分解实现高效前缀和计算
- **关键操作**：
  - `lowbit(x)`：获取 x 的最低位 1
  - `add(pos, val)`：在 pos 位置增加 val
  - `query(pos)`：查询前缀和 [1, pos]
- **时间复杂度**：O(log n)
- **扩展应用**：差分数组、二维树状数组

### 线段树
- **应用场景**：区间查询、区间修改、复杂区间操作
- **核心思想**：将区间划分为多个线段，通过懒标记延迟更新
- **关键操作**：
  - `build(p, l, r)`：建树
  - `pushdown(p)`：懒标记下传
  - `query(l, r)`：区间查询
  - `update(l, r, val)`：区间修改
- **时间复杂度**：O(log n)
- **扩展应用**：懒标记组合（加法+乘法）、动态开点、可持久化

### 字典树
- **应用场景**：字符串存储与查询、异或最值问题
- **核心思想**：利用字符串公共前缀减少存储空间
- **关键操作**：
  - `insert(s)`：插入字符串
  - `query(x)`：查询与 x 异或的最大值（01 字典树）
- **时间复杂度**：O(len)，len 为字符串长度或位数
- **扩展应用**：01 字典树、可持久化字典树

## 使用建议

- **并查集**：
  - 适用于动态连通性问题
  - 路径压缩和按秩合并必须同时使用
  - 带权并查集需维护额外的权值信息
  
- **树状数组**：
  - 单点修改/区间查询：直接使用
  - 区间修改/单点查询：使用差分数组
  - 区间修改/区间查询：维护两个树状数组
  
- **线段树**：
  - 区间操作首选，功能强大
  - 懒标记需注意下传顺序（先乘后加）
  - 空间开 4N，注意数组大小
  
- **字典树**：
  - 字符串问题的高效解决方案
  - 01 字典树适用于异或最值问题
  - 注意节点总数的预估
